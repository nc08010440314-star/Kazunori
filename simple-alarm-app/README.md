# シンプルアラーム

シンプルで使いやすいWebベースのアラームアプリです。

## 機能

- ⏰ 現在時刻の表示
- ⏱️ アラーム時刻の設定
- 🔔 アラーム発動時にビープ音を再生
- 📱 レスポンシブデザイン（スマートフォン対応）
- 🎨 グラデーション背景でシンプルで美しいUI

## 使い方

1. `index.html`をブラウザで開く
2. アラーム時刻を設定する
3. 「設定」ボタンをクリック
4. 設定した時刻になるとアラームが発動します

## 技術

- HTML5
- CSS3
- JavaScript
- Web Audio API
